LOB — live limit order book · Binance.US BTC/USD spot  connecting…

The C++ engine rebuilds the book from a live 100ms feed and computes 3 microstructure signals; the browser shows how the frozen phase-4 model turns them into a trade. Illustrative: live feed is spot, the model was trained on futures, so treat the P&L as a demo — the rigorous out-of-sample number is the phase-4 test result.

top 10 levels each side. bar width = resting size. asks (sellers) above, bids (buyers) below.

signals → model decision

each signal is standardized and multiplied by its trained weight; the products are its contribution to the predicted move (bps). the model just adds them up.

imbalance–
(bid size − ask size) / total at the touch. +1 = only bids (buyers dominate → tends up), −1 = only asks.

micro_dev–
microprice − mid, in $. size-weighted fair value vs the mid; >0 leans up.
–
OFI–
order-flow imbalance: net signed change in top-of-book size this 100ms. >0 = net buying.
–
forecast: predicted mid move over next –ms
–
FLAT
flip to LONG when forecast clears +band, SHORT when it clears −band, else hold — re-checked every 100ms
